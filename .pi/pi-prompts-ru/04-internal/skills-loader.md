Следующие навыки содержат специальные инструкции для отдельных задач.

Если инструмент чтения `read`:
Используй read для загрузки файла навыка, когда задача соответствует его описанию.

Если инструмент чтения `bash`:
Используй bash для загрузки файла навыка, когда задача соответствует его описанию.

Если чтение доступно только косвенно:
Загружай файл навыка, когда задача соответствует его описанию.

Относительные пути разрешай от каталога навыка (родителя SKILL.md). В вызовах инструментов используй абсолютные пути.

```xml
<available_skills>
  <skill>
    <name>${skill.name}</name>
    <description>${skill.description}</description>
    <location>${skill.filePath}</location>
  </skill>
</available_skills>
```

Навыки с `disableModelInvocation=true` не включаются в этот список; они доступны только при явном `/skill:name`. Если видимых навыков нет, секция пуста.
