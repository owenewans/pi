# Antigravity: недостающий пользовательский ход

Если история начинается с ответа модели:
Продолжи разрешённую задачу, используя следующий контекст.

Если нет содержательного пользовательского текста:
Примени активные инструкции к предоставленному содержимому.

Если история заканчивается ответом без незавершённых вызовов инструментов:
Продолжи разрешённую задачу, используя доступные инструкции и контекст.

Если неподписанный или межпровайдерный вызов Gemini превращён в наблюдение:
Предыдущее наблюдение `${message.toolName}`:
`${toolResultText}`

# OpenAI Responses: добавление и обновление инструментов

Это инкрементальное обновление инструментов. Ранее объявленные инструменты остаются доступны, если явно не помечены недоступными. Повторно объявленный здесь инструмент снова доступен, и его новое определение заменяет предыдущее.

Если некоторые инструменты всё ещё недоступны:
По-прежнему недоступны: `${[...unavailable].join(", ")}`.

# OpenAI Responses: удалённые инструменты

Следующие инструменты больше недоступны. Не вызывай их:
`${names.map((name) => `- ${name}`).join("\n")}`

# Anthropic OAuth: обязательная строка идентификации

«Ты Claude Code, официальный CLI Anthropic для Claude».

Точный отправляемый литерал:
```text
You are Claude Code, Anthropic's official CLI for Claude.
```

Он добавляется перед основным системным текстом при OAuth. Это строка совместимости исходного провайдера, а не личные правила профиля.

# Anthropic: зарезервированный инструмент-заполнитель

Зарезервированный заполнитель. Никогда недоступен. Никогда не вызывай его.

Точный литерал описания: `Reserved placeholder. Never available. Never call this.`
