# Работа с задачами и PR GitHub

Шаблоны промптов репозитория в `.pi/prompts/` (на два каталога выше исходного файла этого навыка) определяют рабочий процесс. Полностью прочитайте соответствующий шаблон и следуйте ему. Там, где шаблон содержит `$ARGUMENTS` или `$@`, подставьте номер или URL задачи либо PR из запроса, а также дополнительные инструкции пользователя.

| Запрос | Шаблон |
|---|---|
| Исследовать, проанализировать или исправить задачу | [is.md](../03-commands/is.md), исходник: `.pi/prompts/is.md` |
| Проверить запрос на слияние | [pr.md](../03-commands/pr.md), исходник: `.pi/prompts/pr.md` |
| Завершить работу над задачей или PR: журнал изменений, итоговый комментарий, коммит, отправка, закрытие | [wr.md](../03-commands/wr.md), исходник: `.pi/prompts/wr.md` |

Правила:

- `is.md` только анализирует и предлагает. Реализуйте изменения только по просьбе пользователя, затем продолжайте соблюдать AGENTS.md (проверки, тесты, правила журнала изменений).
- `pr.md` никогда не выполняет переключение на ветку PR или её извлечение в рабочую копию.
- Запускайте `wr.md` только тогда, когда пользователь просит завершить работу, создать коммит или отправить изменения. Публикуйте не более одного итогового комментария GitHub за сеанс, заканчивая его указанной в шаблоне точной строкой уведомления.
- Когда запрос охватывает несколько шагов, например «исправь задачу X и заверши работу», прочитайте все задействованные шаблоны перед началом.
