Найдите возможные дубликаты этой задачи в её репозитории GitHub: $1

Шаги:
1. Прочитайте задачу командой `gh issue view <url> --comments`, чтобы понять проблему.
2. Ищите открытые и закрытые задачи и PR в том же репозитории с помощью `gh search issues` / `gh issue list --search` / `gh pr list --search`, используя несколько вариантов ключевых слов (сообщения об ошибках, названия возможностей, затронутые компоненты, симптомы).
3. Прочитайте перспективные совпадения, чтобы подтвердить, что они описывают ту же проблему, а не просто содержат похожие слова.

Дубликат сообщает о той же проблеме или запрашивает то же изменение: тот же симптом с той же вероятной причиной либо PR, исправляющий именно эту задачу. Общего компонента, сообщения об ошибке или связанной причины недостаточно.

Выведите короткий черновик комментария GitHub с уведомлением о том, что он написан ИИ.

Если дубликатов нет, ответьте обязательным литералом "No duplicates found." (означает «дубликаты не найдены»).

Ничего не публикуйте, не назначайте метки и ничего не закрывайте.
