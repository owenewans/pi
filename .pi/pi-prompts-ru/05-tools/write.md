# write

## описание

Записать содержимое в файл. Создаёт отсутствующий файл и перезаписывает существующий. Автоматически создаёт родительские каталоги.

## краткое описание в системном промпте

Создавать и перезаписывать файлы

## дополнительные инструкции

• Используй write только для новых файлов и полного переписывания.

## параметры

Имена, значения enum и ограничения ниже сохранены. Переведены только описания.

```json
{
  "type": "object",
  "required": [
    "path",
    "content"
  ],
  "properties": {
    "path": {
      "type": "string",
      "description": "Путь записываемого файла, относительный или абсолютный"
    },
    "content": {
      "type": "string",
      "description": "Содержимое для записи в файл"
    }
  }
}
```
