# ls

## описание

Показать содержимое каталога. Элементы сортируются по алфавиту, каталоги получают суффикс /. Включает скрытые файлы. Вывод обрезается до 500 элементов или 50 KB, смотря какой предел достигнут первым.

## краткое описание в системном промпте

Показывать содержимое каталогов

## параметры

Имена, значения enum и ограничения ниже сохранены. Переведены только описания.

```json
{
  "type": "object",
  "properties": {
    "path": {
      "type": "string",
      "description": "Показываемый каталог; по умолчанию текущий"
    },
    "limit": {
      "type": "number",
      "description": "Максимальное число элементов; по умолчанию 500"
    }
  }
}
```
