# tool_search

## описание

# обнаружение инструментов

Ищет по метаданным отложенных инструментов с помощью BM25 и делает совпавшие инструменты доступными для следующего вызова модели.

Некоторые инструменты, например инструменты MCP-серверов, могут быть не предоставлены заранее. Используй этот инструмент (`tool_search`) для поиска нужных. Для обнаружения инструментов MCP всегда используй tool_search.

По умолчанию не активен (`defaultActive=false`).

## краткое описание в системном промпте

Искать ещё не загруженные инструменты и загружать совпадения
