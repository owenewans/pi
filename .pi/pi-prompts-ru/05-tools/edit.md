# edit

## описание

Изменить один файл точной заменой текста. Каждый edits[].oldText должен совпадать с единственным непересекающимся участком исходного файла. Если два изменения затрагивают один блок или соседние строки, объедини их в одно вместо пересекающихся правок. Не включай большие неизменённые участки только ради соединения далёких изменений.

## краткое описание в системном промпте

Точно менять файлы заменой текста, включая несколько непересекающихся правок одним вызовом

## дополнительные инструкции

• Для точечных изменений используй edit. Объединяй изменения одного файла в один вызов.
• Каждый edits[].oldText должен точно и однозначно совпадать с исходным файлом. Совпадения короткие и непересекающиеся; объединяй близкие изменения, не включая большие неизменённые участки.

## параметры

Имена, значения enum и ограничения ниже сохранены. Переведены только описания.

```json
{
  "type": "object",
  "required": [
    "path",
    "edits"
  ],
  "properties": {
    "path": {
      "type": "string",
      "description": "Путь изменяемого файла, относительный или абсолютный"
    },
    "edits": {
      "type": "array",
      "items": {
        "type": "object",
        "required": [
          "oldText",
          "newText"
        ],
        "properties": {
          "oldText": {
            "type": "string",
            "description": "Точный текст одной замены. Должен быть уникален в исходном файле и не пересекаться с другим edits[].oldText в том же вызове."
          },
          "newText": {
            "type": "string",
            "description": "Новый текст для этой точечной замены."
          }
        }
      },
      "description": "Одна или несколько точечных замен. Каждая сопоставляется с исходным файлом, а не с результатом предыдущей правки. Не включай пересекающиеся или вложенные изменения. Правки одного блока или соседних строк объединяй в одну."
    }
  }
}
```
