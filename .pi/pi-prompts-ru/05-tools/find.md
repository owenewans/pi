# find

## описание

Найти файлы по glob-шаблону. Возвращает пути относительно каталога поиска. Учитывает .gitignore. Вывод обрезается до 1000 результатов или 50 KB, смотря какой предел достигнут первым.

## краткое описание в системном промпте

Находить файлы по glob с учётом .gitignore

## параметры

Имена, значения enum и ограничения ниже сохранены. Переведены только описания.

  "properties": {

    "limit": {
