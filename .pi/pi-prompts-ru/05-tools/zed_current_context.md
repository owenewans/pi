# zed_current_context

## описание

Вернуть активный файл Zed, открытые файлы и выделенный текст текущего проекта.

## краткое описание в системном промпте

Читать активный файл Zed, открытые файлы, диапазоны выделенных строк и выделенный текст

## дополнительные инструкции

• Используй zed_current_context, когда пользователь спрашивает, что открыто или выделено в Zed.
