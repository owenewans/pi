# bash

## описание

Выполнить команду bash в текущем рабочем каталоге. Возвращает stdout и stderr. Вывод обрезается до последних 2000 строк или 50 KB, смотря какой предел достигнут первым. При обрезании полный вывод сохраняется во временный файл. Можно задать тайм-аут в секундах.

## краткое описание в системном промпте

Выполнять команды bash (ls, grep, find и другие)

## дополнительные инструкции

• Можно изучать переменные среды PI_* для сведений о текущей модели и сессии.
