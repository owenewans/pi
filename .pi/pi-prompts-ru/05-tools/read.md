# read

## описание

Прочитать содержимое файла. Поддерживаются текст и изображения (jpg, png, gif, webp, bmp). Изображения передаются вложениями. Текст обрезается до 2000 строк или 50 KB, смотря какой предел достигнут первым. Для больших файлов используй offset/limit. Если нужен весь файл, продолжай чтение с offset до конца.

## краткое описание в системном промпте

Читать содержимое файлов

## дополнительные инструкции

• Используй read для изучения файлов вместо cat или sed.
