# codemode

## описание

Выполнить JavaScript, вызывающий другие инструменты. Вход является исходным JavaScript, не JSON и без блока кода; выполняется как тело async-функции в песочнице QuickJS: верхнеуровневые await и return работают. Нет Node, файловой системы, сети и таймеров.
• `await tools.<name>({ ...args })` возвращает строку или объект, если это указано в объявлении инструмента, и отклоняет Promise с Error при сбое. Инструмент, объявляющий объект, может и при ошибке успешно вернуть такой объект; проверяй его поля. Оставшиеся вызовы отменяются по завершении скрипта.
• Необязательная первая строка: `// @options: {"max_output_tokens": 10000, "timeout_ms": 60000}`.

Глобальные объекты и функции:
• `text(value)`, `image(dataUrlOrImageBlock)`, `console.log(...)` и верхнеуровневый return добавляют вывод; `exit()` завершает скрипт. При нескольких текстовых элементах каждый начинается строкой `==> text N/M <==`; строки console идут после остального вывода одним блоком `<console_output>`. image() также сохраняет изображение во временный файл и указывает его путь в результате.
• `store(key, value)` и `load(key)` сохраняют JSON-значения между вызовами codemode.
• `ALL_TOOLS`, `await searchTools(query, { limit?, namespace? })`, `await describeTool(name)`, `await describeNamespace(name)` находят не перечисленные заранее инструменты, например MCP.
• `models`: классификаторы и генерация изображений. Сначала прочитай /home/owenewans/Projects/lunera/pi/packages/coding-agent/docs/codemode.md.

По умолчанию не активен (`defaultActive=false`).

## дополнительные инструкции

• Используй codemode для объединения независимых вызовов (Promise.allSettled), цепочек вызовов и фильтрации большого вывода вместо множества отдельных вызовов.
