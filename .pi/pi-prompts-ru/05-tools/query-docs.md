# query-docs

## описание

Прочитать актуальную документацию и примеры для точного ID Context7. Сначала разреши ID, если его не дал пользователь. Один вопрос темы на вызов, не больше трёх вызовов на вопрос пользователя. Исключай секреты и приватный код.

## параметры

Имена, значения enum и ограничения ниже сохранены. Переведены только описания.

```json
{
  "type": "object",
  "required": [
    "libraryId",
    "query"
  ],
  "properties": {
    "libraryId": {
      "type": "string",
      "pattern": "^/[^/]+/[^/]+(?:/[^/]+)?$"
    },
    "query": {
      "type": "string",
      "minLength": 1
    }
  }
}
```
