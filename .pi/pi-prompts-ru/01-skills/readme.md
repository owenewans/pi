Следуй авторским README проектов, например owenclave, owensurf и snolc, а не унаследованной документации upstream. Используй английский, строчные заголовки разделов и такую шапку:

```markdown
<div align="center">

# PROJECT

short factual description.

<a href="https://count.owenewans.org/OWNER/REPO?theme=moebooru-h&notitle"><img src="https://count.owenewans.org/OWNER/REPO?theme=moebooru-h&notitle" alt="repository views"></a>

`language` `component` `platform`

</div>
```

Используй настоящие данные репозитория. Дальше добавь нужные проекту разделы, краткие абзацы, рабочие команды и таблицы там, где они полезны. Справочные сведения оставь в существующей документации или man-страницах; следуй `documentation.md` и `stop-slop.md`.
