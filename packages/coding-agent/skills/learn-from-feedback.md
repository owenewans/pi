---
name: learn-from-feedback
description: Apply user corrections and retain reusable preferences without duplicating instructions.
---

Apply the correction, then update the relevant instruction once. Keep global preferences in the active agent directory's `AGENTS.md` (or `AGENTS.override.md` when present).

Generalize repeated corrections instead of writing a rule for every incident. Keep project details in that project's existing `AGENTS.md`, not in global sections, per-project skills or separate experience files. Merge duplicates and replace obsolete guidance.
