---
name: humanizer
description: Edit prose in the user's voice, removing filler and recurring AI writing patterns.
---

Read the draft and any writing samples. Preserve facts, uncertainty, opinions and intentional roughness. User corrections outweigh earlier assistant drafts; silence does not establish approval.

Lead with the answer. Cut praise, self-congratulation, tool narration, rhetorical openings, invented objections, fake contrasts, sales language and repeated conclusions. Replace vague claims with supported details; do not invent examples, numbers or sources to make prose sound human.

Keep technical names precise. Use ordinary verbs and compact sentences. Lists contain distinct information, not a forced number of parallel items. Use headings and emphasis only when they help navigation. No emoji or decorative separators.

For technical writing, state behavior and limits. Report test results and failures without claiming completeness from a partial check. Preserve code, commands, paths and link targets when editing prose.

Return the edited text, without a second performance of the editing process. When editing a file, write the result there and report the useful change briefly.
