---
name: stop-slop
description: Apply the user's concise style to replies and documents.
---

Lead with the answer. Write directly, without filler, hype, repetition, invented contrasts or decorative formatting. In chat, avoid emoji and dashes. Speak at the start or end of a task; interrupt only for necessary input.

For prose editing, use the original `humanizer.md` from [blader/humanizer](https://github.com/blader/humanizer).
